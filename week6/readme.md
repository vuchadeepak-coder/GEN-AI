# Week 6 – Generative AI Baseline Evaluation

## Overview

This practical focuses on evaluating the performance of a local Large Language Model (LLM) using a predefined Golden Question Set.

A baseline evaluation system is developed using **Llama 3.2** through Ollama. The system sends questions to the model, compares the generated answers against expected answers using keyword-based scoring, calculates keyword coverage, and classifies responses as PASS, REVIEW, or ERROR.

The first baseline evaluation is documented as **Release v0.1**.

## Project Structure

```text
week6/
├── golden_set.json
├── main.py
├── requirements.txt
└── baseline_results.csv
```

## Features

- Loads a predefined Golden Question Set from JSON.
- Uses Llama 3.2 locally through Ollama.
- Generates answers for predefined questions.
- Compares generated answers with expected keywords.
- Calculates keyword coverage scores.
- Identifies matched and missing keywords.
- Classifies answers as PASS, REVIEW, or ERROR.
- Calculates the average keyword coverage across successful responses.
- Saves evaluation results into a CSV file.
- Records the model name and release version.
- Supports baseline model evaluation and documentation.

## Configuration

The project uses the following model and file configuration in `main.py`.

```python
OLLAMA_URL = "http://localhost:11434/api/generate"

MODEL_NAME = "llama3.2"

INPUT_FILE = "golden_set.json"

OUTPUT_FILE = "baseline_results.csv"
```

The Golden Question Set contains 30 predefined questions covering topics such as:

- Tokenization and tokens
- BPE, WordPiece, and SentencePiece
- Input and output tokens
- API pricing and token usage
- Context windows and rate limits
- Autoregressive generation
- Next-token prediction
- Greedy decoding and sampling
- Temperature, Top-K, and Top-P
- Embeddings and token IDs
- Positional encoding and RoPE
- Transformer architecture

Each question contains an ID, question, expected answer, keywords, and source reference.

## Evaluation Method

The program evaluates every question in the Golden Question Set using the following process:

1. Loads the questions from `golden_set.json`.
2. Sends each question to the Llama 3.2 model through the Ollama API.
3. Receives the generated answer.
4. Compares the answer against the expected keywords.
5. Calculates the keyword coverage percentage.
6. Identifies matched and missing keywords.
7. Assigns a status to each question.
8. Saves the results in `baseline_results.csv`.

### Keyword Scoring

The score is calculated based on the percentage of expected keywords present in the generated answer.

**Formula:**

```text
Score = (Matched Keywords / Total Keywords) × 100
```

### Status Classification

| Score / Condition | Status |
|---|---|
| Score ≥ 60% | PASS |
| Score < 60% | REVIEW |
| Request or execution error | ERROR |
